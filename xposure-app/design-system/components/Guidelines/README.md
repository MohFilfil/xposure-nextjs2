والمصممين قبل مراجعة (design review) أي شاشة جديدة.

**الاستخدام:** كل زوج يوضّح قاعدة واحدة محددة سبق ذكرها نصياً في مكوّن آخر (`Button`, `BrandMotif`)
— هذا المكوّن لا يُضيف قواعد جديدة، بل يُجسّد القواعد الموجودة بصرياً لمن يتصفح النظام سريعاً دون
قراءة كل دليل استخدام على حدة.

**لا تفعل:** لا تُضِف زوجاً جديداً هنا دون إضافة القاعدة النصية المقابلة له أولاً في مكوّنه الأصلي —
هذا المكوّن يعكس قواعد موثّقة، لا يُنشئها.
