مجموعة مدخلات النماذج الأساسية: حقل نصي، قائمة منسدلة، مربع اختيار.

**يوفّره المستهلك:** التسمية (`label`) دائماً إلزامية وظاهرة فوق الحقل — لا `placeholder` بديلاً عن
تسمية.

**الاستخدام:**
- حالة الخطأ: حدود `danger` + رسالة نصية أسفل الحقل مباشرة، تبدأ دائماً بجملة فعلية تشرح لماذا
  (لا "خطأ" وحدها).
- حلقة التركيز (`border-focus`) بسماكة 3px شفافة حول الحقل بأكمله عند focus — واضحة بما يكفي للتنقل
  الكامل بلوحة المفاتيح دون فأرة.
- مربع الاختيار يستخدم `brand` للتحديد (`accent-color`) — هذا أحد المواضع النادرة التي يظهر فيها
  `brand` خارج الأزرار والروابط، لأنه يمثل فعلاً حالة "مُفعّل/مُختار" تفاعلية.
- حقل «سبب الرفض» تحديداً إلزامي دائماً قبل تفعيل زر Reject في `Button` — لا رفض بلا سبب مكتوب.

**لا تفعل:** لا تُعرض رسالة الخطأ بلون `warning` أو نص عادي — دائماً `danger` فقط، لتمييزها فوراً عن
أي نص توضيحي عادي أسفل الحقل.
