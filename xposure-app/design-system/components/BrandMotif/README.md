نمط بصري زخرفي واحد — **الشكل الفعلي مقصوص مباشرة من ملف الشعار نفسه** (`assets/Logos/xposure-aperture-icon.png`)،
لا رسم تقريبي. يُلوَّن عبر CSS mask بلون `ink-muted`، فيتبدّل تلقائياً بين الوضعين دون أي نسخة ثانية
من الصورة.

**يوفّره المستهلك:** لا شيء — هذا نمط ثابت، لا يقبل تخصيص ألوان أو تركيبة مختلفة.

**الاستخدام:**
- **مؤشر التحميل:** نفس أيقونة العدسة تدور ببطء (2.2 ثانية للدورة الكاملة) بدل أي spinner دائري عام
  — هذا هو المؤشر الوحيد المعتمد لأي حالة انتظار في النظام (فحص إصدار جديد، حفظ، تصدير تقرير).
- **الحالة الفارغة:** نفس العدسة ثابتة بحجم أكبر، مصحوبة بشظايا متناثرة خفيفة (svg منفصلة) عند عدم
  وجود بيانات (لا تغييرات مكتشفة، لا مهام، نتيجة بحث فارغة).
- **الغلاف (Cover):** الشعار الكامل نفسه، لا هذه الأيقونة وحدها — راجع مكوّن `Cover`.
- اللون دائماً `ink-muted` بلا استثناء — هذا نمط مساند صامت، ليس عنصراً يلفت الانتباه بلون مميز.

**التنفيذ التقني:** عنصر `<div>` بخلفية `background-color: var(--ink-muted)` مقنّع (`mask-image`)
بصورة العدسة الشفافة، لا `<img>` مباشر — هذا ما يسمح للأيقونة بتغيير لونها تلقائياً مع تبدّل السمة،
رغم أن ملف PNG الأصلي أسود ثابت.

**لا تفعل:**
- لا يظهر هذا النمط أبداً داخل بطاقة أو صف جدول يحتوي بيانات حقيقية — فقط في التحميل والحالة
  الفارغة والغلاف.
- لا تُلوّنه بـ `brand` أو أي لون حالة (success/danger) — هذا يحوّله من "علامة هوية صامتة" إلى
  إشارة حالة مضلِّلة.
- لا يُستخدم كخلفية زخرفية عامة خلف نص أو محتوى قابل للقراءة.
