عرض جنبي (split view) للنص الأصلي مقابل النص الجديد، مع إبراز التغيير الجوهري فقط داخل الفقرة —
لا الفقرة كاملة.

**يوفّره المستهلك:** فقرتا النص (قبل/بعد)، والجزء المتغيّر داخل كل منهما محدداً مسبقاً من محرك
المقارنة (لا يُحسب في الواجهة).

**الاستخدام:**
- كل جزء محذوف يحمل رمز «−» ويحمل أيضاً `text-decoration: line-through`؛ كل جزء مضاف يحمل رمز «+»
  و`underline`. الرمز والتزيين النصي ثابتان دائماً بجانب اللون — لا يُعتمد على اللون وحده أبداً
  (قاعدة سلامة الألوان لذوي عمى الألوان).
- الخلفية اللونية للجزء المتغيّر خفيفة (شفافية) دائماً — الهدف تمييز الموضع لا صبغ الفقرة كاملة.
- العمود الأيمن دائماً "الجديد" والأيسر "السابق" بثبات تام عبر كل شاشات النظام — لا ينعكس الترتيب
  أبداً حتى لو تغيّر سياق الصفحة.
- عند عدم وجود أي تغيير داخل فقرة (بند لم يتأثر مقارنة بالإصدار السابق)، لا تُعرض له بطاقة مقارنة
  أصلاً — هذا المكوّن مخصص فقط للبنود التي يُظهر محرك المقارنة فيها فرقاً فعلياً.

**لا تفعل:** لا تُستخدم ألوان `warning` أو `info` هنا مهما كان نوع التغيير (توضيح، دمج، إلغاء) — هذا
المكوّن يعرض حذفاً/إضافة فقط بلوني `danger`/`success`؛ نوع التغيير نفسه (متطلب جديد، تشديد...) يُعرض
بشارة منفصلة أعلى البطاقة، لا هنا.
