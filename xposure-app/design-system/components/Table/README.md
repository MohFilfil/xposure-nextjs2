الجدول الموحّد لكل قائمة بيانات في النظام: التغييرات، المهام، سجل التدقيق.

**يوفّره المستهلك:** رؤوس الأعمدة، وصفوف البيانات؛ عمودا الحالة والأولوية يحملان `StatusBadge` أو
`PriorityBadge` دائماً، لا نصاً عادياً.

**الاستخدام:**
- التعرّج (striping) بألوان `surface`/`surface-raised` بالتبادل — خفيف عمداً، وظيفته تتبّع السطر
  بالعين فقط، لا الزخرفة.
- حالة hover تكسو الصف كاملاً بـ `surface-overlay` وتُظهر مؤشر يد (cursor: pointer) — فقط إذا كان
  الصف قابلاً للنقر لفتح التفاصيل.
- رأس الجدول ثابت الأسلوب دائماً: `ink-muted`، حجم `caption`، بلا خلفية مميزة — لا يُبرز الرأس بلون
  `brand` أو خلفية داكنة إضافية.
- عمود الأولوية دائماً قبل عمود الحالة في ترتيب الأعمدة (القرار قبل السير)، ما لم يتطلب السياق
  خلاف ذلك صراحة.

**لا تفعل:** لا يُستخدم هذا الجدول لعرض أكثر من 6–7 أعمدة على الشاشات الأصغر من سطح المكتب؛ أعمدة
إضافية تنتقل لقائمة "..." أو لصفحة التفاصيل بدل تصغير الخط لإدخالها قسراً.
