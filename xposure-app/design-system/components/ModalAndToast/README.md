**النافذة المنبثقة (Modal):** تأكيد لأي إجراء لا رجعة فيه أو يُسجَّل في سجل التدقيق بشكل دائم.

**التنبيه (Toast):** إشعار عابر (4–5 ثوانٍ) لنتيجة إجراء تم للتو.

**يوفّره المستهلك:**
- Modal: عنوان الإجراء، جملة تحذير تشرح الأثر (لا رجعة/يُسجَّل)، وزرَي إلغاء/تأكيد.
- Toast: نوع النتيجة (نجاح/خطأ) ونص وصفي واحد.

**الاستخدام:**
- Modal يُستخدم فقط للإجراءات التي **لا رجعة فيها** (رفض، حذف) — إجراء عادي (حفظ مسودة) لا يحتاج
  نافذة تأكيد، فقط toast بعد الحفظ مباشرة.
- زر التأكيد داخل Modal يحمل دائماً لون الإجراء نفسه (`danger` للرفض) لا `brand` — لون الزر يعكس
  خطورة الفعل، لا كونه "الزر الرئيسي" فقط.
- Toast الخط الجانبي الملون (3px) + رمز (✓/✕) معاً — مرة أخرى، لا اعتماد على اللون وحده.
- Toast لا يحجب أي عنصر تفاعلي أسفل الشاشة؛ يظهر أعلى يسار الشاشة دائماً (بعيداً عن لوحة المراجعة
  السفلية الثابتة إن وُجدت).

**لا تفعل:** لا تُستخدم النافذة المنبثقة لعرض معلومات فقط بلا قرار مطلوب من المستخدم — هذا استخدام
لبطاقة أو قسم عادي في الصفحة، لا Modal.
